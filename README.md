비공식 블록 생성기 v0.1.2

변경 사항
- 여러 카테고리를 한 번에 만들고 등록할 수 있습니다.
- + 카테고리 추가 버튼을 추가했습니다.
- 각 카테고리는 자기 블록 목록을 따로 가집니다.
- 인디케이터는 내부 코드(flow 등)를 직접 쓰지 않고 엔트리 화면의 한글 카테고리 이름으로 선택합니다.
  시작 / 흐름 / 움직임 / 생김새 / 붓 / 소리 / 판단 / 계산 / 자료 / 함수 / 데이터분석 / 인공지능 / 확장 / 하드웨어
- 같은 설정을 여러 번 적용해도 동일 카테고리가 중복 생성되지 않습니다.
- 삭제한 생성기 카테고리도 다음 적용 때 작품 화면에서 정리됩니다.
- v0.1.0, v0.1.1에 저장된 단일 카테고리 설정을 자동 변환합니다.

설치
1. 이 폴더를 원하는 위치에 둡니다.
2. Chrome에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다"를 누릅니다.
5. 이 폴더를 선택합니다.
